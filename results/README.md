# Resultados

## Contenido versionado

`reference/` contiene copias pequenas de las metricas e imagenes utilizadas en
el informe doctoral.

## Contenido no versionado

Las corridas completas, modelos, PLY, videos y archivos Blender se conservan
fuera de Git por tamano. Las rutas originales estan registradas en los
documentos y manifiestos.

Las nuevas ejecuciones deben escribirse en `outputs/experiments/`, no dentro de
`results/reference/`.
