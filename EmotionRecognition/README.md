# Prototipos historicos

Esta carpeta corresponde al proyecto inicial de Visual Studio y se conserva
para trazabilidad.

Incluye pruebas exploratorias de:

- CLIP para clasificacion facial;
- FER y seguimiento ocular;
- extraccion de variables VREED;
- clasificadores tabulares;
- Transformers y fusion multimodal no integrados.

Estos archivos no son los experimentos reproducibles presentados como
resultado doctoral. Algunos contienen rutas locales, supuestos preliminares y
comentarios de desarrollo.

Los flujos vigentes estan en `../experiments/` y las implementaciones
validadas en `../tools/`. Los modelos, graficos, reportes y datasets generados
por estos prototipos estan excluidos de Git.
