# Dependencias

| Archivo | Uso |
|---|---|
| `base.txt` | VREED y procesamiento cientifico general |
| `eye.txt` | Android, OpenCV y MediaPipe con Python 3.12 |
| `reconstruction.txt` | ToF, evaluacion y soporte 3DGS |
| `validated_versions.md` | versiones medidas en los entornos originales |

PyTorch y `gsplat` deben instalarse de acuerdo con la version CUDA del equipo.
La referencia utilizada se documenta en `external/README.md`.
